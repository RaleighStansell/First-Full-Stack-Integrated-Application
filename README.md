# First-Full-Stack-Integrated-Application
This project is my first attempt at fully integrating a full stack app.


Likewise, I used Microsoft Copilot to improve the application itself and its performance. It helped to add more error catching features and pointed out how to structure my code to remove errors in loading. The biggest challenge I faced was getting everything to integrate, I managed to get some form of integration at the end but nothing more. Copilot helped me identify issues and causes of my inability to integrate the features properly. I learned that Copilot was an excellent feature to improving code, specifically for creating repetitive features and address integration bugs.
